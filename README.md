# Calopro

Web-app pour gérer 3 meublés à Saint-Malo en bail mobilité : vitrine et candidature, livret d'accueil et QR par équipement, gestion propriétaire.

## Arborescence

- `docs/01-prd/` : PRD v1 (origine) et PRD v2 (MVP perso, version de référence)
- `docs/02-system-design/` : architecture, modèle de données, flux
- `docs/03-maquettes/` : écrans et maquettes
- `skills/` : skills Claude utilisés sur le projet
